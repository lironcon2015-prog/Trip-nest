# Navigo 🛫 — TripNest

אפליקציית PWA משפחתית לניהול חופשות: מחיצה לכל טיול עם כל המסמכים, תוכנית טיול,
צ׳ק-ליסטים ותקציב — מסונכרן בין שני בני הזוג דרך שרת Navigo בקלאודפלייר (שינוי של
אחד מופיע אצל השני תוך שנייה), עם סריקת Gmail של שתי התיבות וסוכן AI מבוסס Gemini.
קבצי המסמכים נשמרים בתיקיית Google Drive משותפת.

**Vanilla JS · ללא build · IndexedDB · Service Worker · עברית RTL**

## עקרונות פרטיות

- הנתונים נשמרים **אצלכם**: במכשיר (IndexedDB), בשרת Navigo שרץ **בחשבון ה-Cloudflare שלכם** (קוד פתוח בתיקיית `server/`), וקבצי המסמכים בתיקיית הדרייב המשותפת שלכם. השרת שומר כל לילה גיבוי בתיקיית הדרייב.
- הגישה ל-Drive ול-Gmail נעשית דרך **גשר Apps Script שרץ בחשבון Google שלכם** — הקוד שלו פתוח בתיקיית `bridge/`, מוגן בטוקן סודי.
- **צילומי דרכון נשמרים במכשיר בלבד** — לא עולים לשרת ולא לדרייב, לא נשלחים ל-Gemini, לא נכללים בגיבויים.
- אחרי חיבור לשרת, הטוקנים של הגשרים ומפתח ה-Gemini נשמרים **בשרת בלבד** — הם נמחקים מהטלפונים ולא יוצאים ממנו בשום תשובה או גיבוי. טלפון מתחבר עם קוד, וטלפון שאבד מנותק מהטלפון השני.

## הפעלה ראשונה — צ׳ק-ליסט

### 1) GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / root → Save.
האפליקציה תעלה ל-`https://<user>.github.io/trip-nest/`.

### 2) גשר Apps Script (כ-5 דקות, כל אחד בחשבון ה-Gmail שלו — בלי Cloud Console!)
1. היכנסו ל-[script.new](https://script.new) כשאתם מחוברים לחשבון ה-Gmail הנכון.
2. מחקו את התוכן והדביקו את הקובץ [`bridge/bridge.gs`](bridge/bridge.gs) במלואו.
3. בשורה הראשונה של הקוד החליפו את `SECRET_TOKEN` למחרוזת סודית ארוכה משלכם.
4. **Deploy → New deployment → Web app** → Execute as: **Me** · Who has access: **Anyone** → Deploy → אשרו את ההרשאות (Drive + Gmail של החשבון שלכם בלבד).
5. העתיקו את כתובת ה-Web app (מסתיימת ב-`/exec`).
6. באפליקציה: הגדרות → גשר Google → הדביקו את הכתובת ואת הטוקן → "🔌 בדיקת חיבור" אמורה להציג את המייל שלכם.
7. **סריקה של שתי התיבות:** החליפו ביניכם את כתובת הגשר והטוקן, והדביקו כל אחד את של השני
   בהגדרות תחת "💞 הגשר של בן/בת הזוג". מעכשיו כל סריקת מייל מכסה את שתי התיבות,
   וכל מייל בתוצאות מסומן מאיזו תיבה הגיע.

> אזהרת "Google hasn't verified this app" באישור ההרשאות היא צפויה — זה הסקריפט **שלכם** שרץ בחשבון **שלכם**. לחצו Advanced → Go to project.

### 3) מפתח Gemini (חינם)
[aistudio.google.com/apikey](https://aistudio.google.com/apikey) → Create API key →
הדביקו בהגדרות → סוכן AI. (בכל מכשיר; המפתח לא מסתנכרן.)

### 4) תיקייה משותפת בדרייב
במכשיר הראשון: הגדרות → "➕ צור ושתף (מכשיר ראשון)" → הזינו את המייל של בן/בת הזוג.
במכשיר השני: הגדרות → "🔗 התחבר לקיימת (מכשיר שני)" — הגשר מאתר את התיקייה ששותפה אליכם.

### 5) השרת בקלאודפלייר (פעם אחת, כחצי שעה — כמו ב-MGivatayim)

השרת (`server/`) מחליף את הסנכרון דרך הדרייב: מהיר, בזמן אמת בין שני הטלפונים, ועובד
מכל רשת בחו״ל — Gemini ו-Gmail נקראים ממנו, מאירופה, ולא מהטלפון. עד שמחברים טלפון,
האפליקציה עובדת בדיוק כמו קודם. לא צריך להתקין כלום.

1. **dash.cloudflare.com** (אותו חשבון של `lironcon.com`) ← **Workers & Pages** ← **Create application**
   ← ליד **Import a repository** ← **Get started** ← בוחרים את `Trip-nest`
   (בפעם הראשונה: Connect GitHub ← Only select repositories ← `Trip-nest`).
2. במסך ההגדרות:
   - **Project name:** `navigo` — **בדיוק כך**, אותיות קטנות.
   - **Build command:** ריק. **Deploy command:** להשאיר `npx wrangler deploy`.
   - **Root directory** (תחת Advanced settings): `server`
   ← **Save and Deploy**. אחרי דקה-שתיים: "Success".
3. בשרת ← **Settings** ← **Builds**: ב-**Branch control** — רק `main`; ב-**Build watch paths** — `server/*`
   (שינוי באפליקציה בלבד לא מפעיל פריסה).
4. בשרת ← **Settings** ← **Domains & Routes** ← **Add** ← **Custom domain** ← `navigo.lironcon.com`.
   **לא `workers.dev`** — הסלולרי שלך חוסם אותו.
5. בשרת ← **Settings** ← **Variables and Secrets** ← **Add** ← Type: **Secret**:
   - `FAMILY_CODE` = מחרוזת אקראית ארוכה (12 תווים לפחות), למשל מתוך מנהל הסיסמאות. זה הדבר היחיד
     שטלפון חדש צריך — שמרו אותו במקום בטוח. **Deploy** בסוף.
6. בדיקה: פותחים בדפדפן `https://navigo.lironcon.com` — צריך להופיע טקסט שמכיל `"service":"navigo"`.
7. **הגשר שלך — עדכון ל-v1.5.0** (מסלול העקיפה דרך גוגל, לרשת שחוסמת את השרת): בעורך הגשר
   ב-script.google.com מדביקים את [`bridge/bridge.gs`](bridge/bridge.gs) המלא (משאירים את
   `SECRET_TOKEN` שלכם) ← בוחרים `testForward` ← **Run** ← מאשרים הרשאה (גישה לרשת חיצונית) ←
   ביומן "השרת ענה (200)" ← **Deploy** ← **Manage deployments** ← העיפרון ← Version: **New version** ←
   **Deploy**. (לא "New deployment" — זו כתובת חדשה.) הגשר של בת הזוג לא חייב להתעדכן.
8. **בטלפון שלך:** הגדרות ← **שרת Navigo** ← מקלידים את `FAMILY_CODE` ← **חיבור לשרת**. הטלפון מושך
   קודם את העדכונים האחרונים מהדרייב, מעביר לשרת את הגשרים (שלך ושלה), את מפתח ה-Gemini ואת
   תיקיית הדרייב, מעלה את כל הנתונים — ומוחק את הטוקנים והמפתח מהטלפון.
9. **בטלפון שלה:** בטלפון שלך ← **חיבור מכשיר נוסף** ← קוד בן 8 תווים (בתוקף 10 דקות, פעם אחת) ← בטלפון
   שלה: הגדרות ← שרת Navigo ← מקלידים את הקוד. אפשר גם להקליד שם את `FAMILY_CODE`.

**אחרי החיבור:** סנכרון בזמן אמת; כל לילה (בסביבות 03:40) השרת שומר את כל הנתונים בתיקיית הדרייב
המשותפת, בקובץ `navigo-backup-<יום>.json` — שבעת הימים האחרונים. טלפון שאבד: הגדרות ← שרת Navigo ←
**המכשירים** ← **ניתוק**. ברשת שחוסמת את השרת האפליקציה עוברת לבד דרך הגשר בגוגל, ובתחתית ההגדרות
מופיע "· דרך גוגל".

**בקלאודפלייר — בלי Bot Fight Mode, Challenge או חסימת מדינות על הדומיין:** אתגר של קלאודפלייר מחזיר
דף HTML במקום תשובה, ודווקא כתובות של eSIM ו-VPN בחו״ל מקבלות אותו יותר.

| מה רואים | מה זה | מה עושים |
|---|---|---|
| "השרת לא זמין" בחיבור | השרת לא פרוס, או שהדומיין עוד לא מחובר | שלבים 1–6; הבדיקה בשלב 6 |
| "בשרת עוד לא הוגדר FAMILY_CODE" | חסר הסוד, או קצר מ-12 תווים | שלב 5, ואז Deploy |
| "הקוד שגוי או שפג תוקפו" | טעות הקלדה, או קוד חד-פעמי שכבר נוצל / עברו 10 דקות | קוד חדש מ"חיבור מכשיר נוסף" |
| "יותר מדי ניסיונות שגויים" | 8 קודים שגויים ברבע שעה | מחכים רבע שעה |
| הבנייה בקלאודפלייר נכשלה ומוזכר "name" | שם השרת אינו `navigo` | Settings ← שינוי שם ל-`navigo` |
| התיבה שלה לא נסרקת | הגשר שלה לא היה מוגדר בטלפון שחובר ראשון | לחבר גם את הטלפון שלה — הוא מעביר את הגשר שלו |

### 6) התקנה על מסך הבית
- **iPhone**: Safari → שיתוף → "הוסף למסך הבית".
- **Android**: Chrome → תפריט ⋮ → "הוספה למסך הבית".

## עדכון גרסה

כשעולה גרסה חדשה ל-GitHub Pages, האפליקציה מזהה אותה לבד (בפתיחה ובכל חזרה אליה)
ומציגה באנר "🚀 גרסה חדשה של Navigo מוכנה" — לחיצה על **עדכון** מתקינה וטוענת מחדש.
אפשר גם לבדוק ידנית: הגדרות → למטה → "🔄 בדיקת עדכון גרסה".
הנתונים לא נמחקים בעדכון — הם ב-IndexedDB ובדרייב, לא ב-cache.

```
├── index.html        # מעטפת האפליקציה (SPA יחיד)
├── sw.js             # Service Worker — חייב להישאר בשורש (scope)
├── manifest.json     # PWA manifest
├── version.json      # גרסה נוכחית (לבדיקת עדכונים)
├── css/
│   └── style.css
├── js/               # מודולי האפליקציה (נטענים לפי הסדר ב-index.html)
│   ├── db.js         # IndexedDB
│   ├── ui.js         # רכיבי UI משותפים
│   ├── gemini.js     # קריאות Gemini API
│   ├── mrz.js        # קריאת דרכון מקומית (Tesseract + MRZ)
│   ├── merge.js      # כללי המיזוג — משותפים לאפליקציה ולשרת
│   ├── google.js     # לקוח הגשר — Drive, Gmail (לפני חיבור לשרת)
│   ├── server.js     # לקוח השרת — חיבור, סנכרון, עדכונים חיים, עקיפה דרך גוגל
│   ├── members.js    # בני משפחה
│   ├── vault.js      # כספת דרכונים
│   ├── documents.js  # מסמכים
│   ├── itinerary.js  # ציר זמן
│   ├── trips.js      # טיולים
│   ├── agent.js      # סוכן AI
│   ├── settings.js   # הגדרות
│   └── app.js        # אתחול וניווט
├── server/           # שרת Navigo בקלאודפלייר — נפרס מגיטהאב (Workers Builds)
│   ├── worker.js     # Worker + Durable Object אחד ("המשפחה")
│   ├── merge.js      # נוצר מ-js/merge.js (tools/make-server.mjs) — לא לערוך
│   └── wrangler.toml
├── bridge/
│   └── bridge.gs     # גשר Apps Script — מודבק ב-script.new (לא נטען מהאתר)
├── tools/make-server.mjs
├── tests/            # smoke · server (workerd) · sync (שני טלפונים) · e2e (Chromium)
├── icons/            # אייקוני PWA
└── docs/             # מסמכי עיצוב ותכנון
```

## פיתוח

```bash
python3 -m http.server 8080   # ואז http://localhost:8080
node tests/smoke.mjs          # בדיקת עשן ללקוח הגשר
npm install --no-save miniflare fake-indexeddb
node tests/server.mjs && node tests/sync.mjs && node tests/e2e.mjs
```

בכל commit שמשנה קוד יש לעדכן יחד: `sw.js` (CACHE_VERSION), `version.json`, `index.html` (`_BUNDLE_VERSION`).
שינוי ב-`bridge/bridge.gs` מחייב פריסה מחדש של הגשר (Deploy → Manage deployments → Edit → New version).

גשר v1.3.0 הוסיף את `fileGet`/`filePut` — נדרש לגיבוי ארכיון שיחות הסוכן בדרייב. עם גשר ישן יותר האפליקציה ממשיכה לעבוד והארכיון נשמר במכשיר בלבד.
